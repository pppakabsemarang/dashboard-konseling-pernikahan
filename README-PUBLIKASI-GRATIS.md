# Dashboard Konseling Pernikahan — DP3AKB Kabupaten Semarang

Paket ini disiapkan untuk menerbitkan dashboard sebagai website yang dapat dibuka melalui tautan internet. File utama website adalah `index.html`.

## Pilihan 1 — GitHub Pages (gratis)

1. Masuk atau buat akun di https://github.com/ .
2. Klik **New repository**.
3. Isi nama repositori, misalnya `dashboard-konseling-pernikahan`.
4. Pilih **Public** (GitHub Pages pada paket gratis memerlukan repositori publik untuk penggunaan ini), lalu buat repositori.
5. Pada repositori tersebut, pilih **Add file → Upload files**.
6. Unggah `index.html` dari paket ini, kemudian klik **Commit changes**.
7. Buka **Settings → Pages**.
8. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
9. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
10. Setelah publikasi selesai, alamat website mengikuti pola:

   `https://NAMA-AKUN.github.io/dashboard-konseling-pernikahan/`

   Ganti `NAMA-AKUN` dengan nama akun GitHub yang digunakan. Tautan persis akan terlihat di bagian **Settings → Pages**.

Untuk memperbarui website, unggah kembali atau edit `index.html` pada repositori yang sama.

## Pilihan 2 — Netlify Drop (unggah cepat)

1. Buka https://app.netlify.com/drop .
2. Seret folder yang berisi `index.html` ke halaman tersebut, atau pilih folder dari komputer.
3. Ikuti petunjuk Netlify untuk menerbitkan/mengklaim proyek. Paket Free saat ini tersedia dengan batas penggunaan bulanan.
4. Setelah berhasil, Netlify memberikan alamat website publik yang dapat dibagikan.

## Catatan sebelum dipublikasikan

- Pastikan pimpinan/pejabat berwenang menyetujui publikasi halaman dan informasi kontak petugas yang tercantum.
- Periksa kembali nomor WhatsApp, tautan Google Form, serta izin akses Google Docs agar dapat dibuka oleh masyarakat yang dituju.
- Website ini bersifat statis. Hosting hanya menayangkan halaman; pengiriman pendaftaran tetap melalui Google Form yang sudah tertaut. Data jawaban formulir dikelola pada akun Google pemilik formulir, bukan disimpan oleh website ini.
- Jangan memasukkan atau mengunggah data pribadi/identitas korban atau pemohon ke repositori publik. Isi repositori yang dipublikasikan dapat dilihat siapa pun.
- Hosting gratis menyediakan alamat bawaan penyedia. Nama domain khusus seperti `.go.id` atau domain instansi sendiri biasanya memerlukan proses dan/atau biaya tersendiri.
